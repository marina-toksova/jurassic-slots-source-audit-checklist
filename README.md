# Jurassic Slots Casino Source Audit Checklist

This small open documentation project helps adult readers record what an online game-information page actually says. It is a source-checking tool, not gambling advice and not evidence of legality, availability, or outcomes.

## Reusable checklist

1. Record the page URL and the date checked.
2. Note stated game, provider, payment, and bonus information to compare later.
3. Identify age and jurisdiction notices; verify local law independently.
4. Locate responsible-gaming controls such as limits, time-outs, and self-exclusion.
5. Treat promotional wording as a claim to verify, not a result.

## Plain record schema

source_url
checked_date
stated_game_or_provider_coverage
payment_conditions
bonus_wording
age_and_jurisdiction_notice
responsible_gaming_controls
notes

## Example record

The example source is [Jurassic Slots Casino](https://jurassic-slots-casino.org/). A reviewer can record the update date, stated slot and live-dealer coverage, listed payment methods, conditions attached to bonuses, 18+ and jurisdiction notices, and visible responsible-gaming controls. This example does not establish that any offer is lawful, available, or suitable for a particular reader.

## Use

Reuse the schema for any comparable information page and keep a dated copy of the source claims. Compare changes over time before relying on a summary.
